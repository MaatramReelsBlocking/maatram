MAATRAM SHIELD

Set up Maatram Shield on Android

Shield is the permission that lets Maatram pause the apps you choose during a Hard Lock. Without it, the lock still runs, but it cannot stop an app from opening. This guide takes about 3 minutes.

Blocking is only confirmed inside the Android app. A website cannot check whether Shield is working. Open Maatram on your phone and look at the Shield status there. If it says it is not running, blocking is not active, whatever the timer shows.

Before you start

You need an Android phone with the Maatram app installed, and about 3 minutes. You will leave the app to open Android Settings and come back.

Turn Shield on

  1. Open Maatram and go to App Gate. In the Shield card, tap Enable Shield.If the button says the setting is blocked, go to step 2.
  2. On Android 13 and later, the Accessibility switch is greyed out for apps installed outside the Play Store. Open Settings → Apps → Maatram, tap the ⋮ menu at the top right, and choose Allow restricted settings. Confirm with your PIN or fingerprint.The menu is only there after the app has been installed for a moment. If it is missing, close Settings and try again.
  3. Go back to Settings → Accessibility (or the Shield card, which opens it for you). Find Maatram Shield and switch it on. Accept the warning. It says the service can read screen content. Maatram uses that only to pause blocked apps during a Hard Lock. It does not send screen content anywhere.
  4. Return to Maatram. The Shield card should now say Shield is on and running. If it still says it is off, see the fixes below.

Check that it is working

  1. Start a short Hard Lock (5 minutes) with at least one app selected, such as YouTube.
  2. Open that app. It should be sent back to the home screen straight away.
  3. Stop the Hard Lock, then open the app again to confirm it works normally.

If the app still opens during a Hard Lock, follow the fixes below, then report it with the blocking issue form.

Fixes when setup fails

"Restricted setting" and the switch is greyed out

Use Settings → Apps → Maatram → ⋮ → Allow restricted settings, then enable Maatram Shield. This is an Android 13+ safety rule for apps not from the Play Store. Maatram cannot skip it.

Shield turns off after you close the app or restart the phone

Set Maatram's battery use to Unrestricted (Settings → Apps → Maatram → Battery). Then open the recent apps view and lock Maatram there (usually by pressing its card, then choosing Lock or Keep open).

Samsung phones

Remove Maatram from Sleeping apps and Deep sleeping apps (Settings → Battery → Background usage limits). Then set Battery to Unrestricted, as above.

Oppo, Realme, Vivo, Xiaomi

Allow Auto-start for Maatram in the phone's security or app manager, and allow background activity. Each brand puts this in a different menu, so search the settings for "auto-start".

Google Pay or banking apps stop working

Some payment apps refuse to run on phones with Maatram installed, even with Shield off. We are still investigating this. Please report it with your phone model and Android version using the blocking issue form.

Blocking still does not work after all of the above

Make sure a Hard Lock is running and the app is selected. Note the Maatram version and the app's version (Settings → Apps), then send them with your phone model using the blocking issue form.

Turn it off

You can switch Shield off at any time in Settings → Accessibility → Maatram Shield. Blocking stops until you turn it on again. Your points and history stay as they are.
